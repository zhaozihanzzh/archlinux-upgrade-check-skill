#1 2026-08-22 09:15:00

今天 pacman -Syu 之后重启，系统卡在 starting version 2.41 就不动了，进不了桌面。从 live USB chroot 进去看，是 glibc 2.41-1 这次升级把 /lib64 从目录改成了指向 lib 的软链。

我之前 /lib64 是个目录（里面有手放的库），glibc 2.41 升级时 pacman 拒绝覆盖，留下半升级状态，结果重启起不来。

解决：升级前先 rm -rf /lib64 && ln -s lib /lib64，把 /lib64 变成软链，再跑 pacman -Syu。这是 glibc 2.41 的已知手动干预项，官方 news 也发了公告。升级 glibc 前一定先处理 /lib64。
